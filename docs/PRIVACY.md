# 隐私说明

## 默认保存在本机的数据

随阅把以下内容保存在 Electron 的 `userData` 目录：

- 网站、文件夹和自定义文章入口；
- 文章缓存、阅读进度和翻译缓存；
- 已完成阅读的文章正文、摘要、分类和标签（SQLite）；
- 站点健康信息与最近的运行错误；
- 阅读字号、版心、翻译授权状态和加密后的 Groq 密钥。

JSON 文件、SQLite 文件及迁移备份会尽可能使用仅当前用户可读写的权限。数据库升级前，如已有文章数据，会先生成一次同目录备份。运行诊断是有界的，只保留最近 300 条；网络 URL 的查询参数会在日志中隐藏。

## 何时会访问第三方服务

- **网站与文章抓取：** 为发现和提取文章，应用会访问用户添加的网站、RSS、站点地图及用户配置的镜像服务。
- **划词翻译：** 默认关闭。用户在“隐私与 AI”中明确启用后，选中的文本才会发送给当前翻译提供方。翻译服务可能仍能看到请求文本和来源 IP；本地日志不保存文本对应的 URL 查询值。
- **Groq 知识分析：** 只有配置 Groq API 密钥后，已完成阅读的文章文本才会发送到 Groq，以生成中文摘要、分类和标签。
- **外部链接：** 原文和镜像由系统默认浏览器打开。

第三方服务按各自的隐私政策处理收到的数据。不要对包含敏感或机密信息的文本启用远程翻译或 AI 分析。

## 凭据

在 macOS 上，通过界面保存的 Groq API 密钥使用 Electron `safeStorage` 加密。若系统安全存储不可用，应用拒绝明文保存密钥；此时可通过进程环境变量 `GROQ_API_KEY` 提供。

## 删除本机数据

“来源管理”可以清理浏览器缓存。若要彻底删除全部数据，请先退出应用，再删除该应用对应的 Electron `userData` 目录。建议删除前保留 `reading-knowledge.db` 及同名迁移备份，以免丢失知识库。

本项目不会把运行数据或密钥写入仓库。
