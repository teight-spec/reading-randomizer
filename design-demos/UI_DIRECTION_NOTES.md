# 随阅 UI 优化方向

## 当前界面的核心问题

1. 来源管理、导入、添加网站、缓存维护等低频任务常驻左栏，挤压阅读空间。
2. 顶栏操作数量过多且权重接近，“下一篇”这个核心动作不够突出。
3. 阅读设置悬浮在文章上方，打断标题区的视觉连续性。
4. 翻译、镜像、来源管理混在同一层级，阅读任务和维护任务没有分区。
5. 中英文 UI 文案混用，按钮语气和命名不统一。

## Demo A：沉浸阅读

- 适合作为默认主界面。
- 把导航压缩为窄侧栏，管理功能只保留一个入口。
- 阅读进度、文章信息、主要动作形成清晰的三层结构。
- “下一篇”是唯一主按钮，其余均为次要操作。

## Demo B：编辑部 / 每日一期

- 品牌感最强，适合强化“每天遇见一篇好文章”的产品心智。
- 使用杂志式标题和期号建立仪式感。
- 来源导航退到次要层级，文章本身成为封面。
- 不建议把这种大标题版式用于所有长文章，可用于首页或文章开场。

## Demo C：阅读翻译工作台

- 适合高频阅读英文并划词翻译的用户。
- 翻译从漂浮弹窗改为可固定、可收起的右侧面板。
- 左侧资料库、中央文章、右侧翻译三块职责稳定。
- 当翻译面板关闭时，中央阅读区应自动扩大。

## 推荐组合

以 Demo A 作为默认框架，吸收 Demo C 的可收起翻译面板；Demo B 的编辑式开场可作为“今日一篇”首页或文章加载后的首屏样式。

## Demo D：简约高雅融合版

- 以 Demo A 的窄侧栏和单一主按钮作为骨架。
- 吸收 Demo B 的衬线标题、期号、细分隔线和编辑式元信息。
- 配色收敛为暖白、炭黑、暖灰和少量酒红，不再增加第二强调色。
- 左栏仅保留导航和分类摘要，具体来源及管理表单进入二级界面。
- 推荐以此稿作为后续实现基准；划词翻译仍可采用 Demo C 的可收起右侧面板。
